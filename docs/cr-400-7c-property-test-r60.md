## Rule

> CR §400.7c — If an effect causes an object to move from one
> zone to another, the object goes to the owner's version of
> that zone.

## Property

For every `*Card C` and every card-bearing zone `Z` on every
seat `S` (Hand, Library, Graveyard, Exile, CommandZone),

    Z.contains(C)  ⟹  S == C.Owner

Battlefield is excluded — `Permanent.Controller` may legitimately
differ from `Permanent.Card.Owner` (Mind-Control / Gilded-Drake
trades), and §400.7c only governs zone-to-zone movement.
