## Rule

> CR §108.3 — The owner of a card in the game is the player who started
> the game with it in their deck.
>
> CR §400.7 — An object that moves from one zone to another becomes a new
> object with no memory of its existence in its previous zone, with some
> exceptions (commander zone, exile-linked, etc.).
>
> CR §400.7c — If an effect causes an object to move from one zone to
> another, the object goes to the owner's version of that zone.

(The task prompt's `§702.91` reference is shorthand for the permanent-
lifetime ownership invariant — the actual numeric CR §702.91 is the
"Improvise" keyword and is not load-bearing for this test.)

## Property

For all `*Permanent P` with `P.Owner != P.Controller` (split via
Bribery / Control Magic / Hostage Taker / Gilded Drake / Mind Control),
for all exit effects `E` in `{destroy, exile, bounce, sacrifice}`,

    post(E(P))  ⟹  P.Card ∈ gs.Seats[P.Owner]'s destination zone
                  ∧  P.Card ∉ gs.Seats[P.Controller]'s zones

Battlefield is excluded because `Permanent.Controller` may legitimately
differ from `Permanent.Card.Owner` while the permanent is in play.
§400.7c only governs zone-to-zone movement, not in-battlefield control.
